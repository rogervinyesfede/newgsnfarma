## CONTEXT DEL PROJECTE (llegeix-ho primer)

Abans de fer res en aquest projecte, **carrega i llegeix sencer** `WebGSNFarma.md`, que és a la carpeta de projecte `New GSNFarma`, un nivell per sobre d'aquest repositori (`..\WebGSNFarma.md`) i fora de Git (context, decisions, estat, pendents i regles de treball). **Cada vegada que facis una modificació, actualitza aquest fitxer** (data, seccions afectades i historial de canvis). No desplegar a Vercel sense que l'usuari ho demani. **Tot el que es generi** es guarda a la carpeta del projecte real `…\Projects\New GSNFarma`: el codi dins de `gsnfarma-web-v1`, i els documents/informes/Excel a `New GSNFarma\Documentacio\` (fora del repo). No crear fitxers a `…\Projects\GSN Farma Labs Group`.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
